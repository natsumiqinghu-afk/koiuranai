# ママミーヤ - 育児ブログサイト

## 📝 記事の投稿方法

### 1. 新しい記事を作成

`_posts` フォルダに以下の形式でファイルを作成します：

```
_posts/YYYY-MM-DD-title.md
```

**例：** `_posts/2025-02-17-sleep-tips.md`

### 2. YAML Front Matter（記事の設定）

各記事の冒頭に以下の設定を記述します：

```yaml
---
layout: post
title: "記事のタイトル"
date: 2025-02-17
categories: [カテゴリ1, カテゴリ2]
age: "対象月齢"
tags: [タグ1, タグ2, タグ3]
---
```

#### 利用可能なカテゴリ
- 寝かしつけ
- 離乳食
- 時短
- お出かけ
- イヤイヤ期
- 兄弟
- 健康
- 遊び
- その他（自由に追加可能）

#### 利用可能な月齢
- 0-3ヶ月
- 4-6ヶ月
- 7-9ヶ月
- 10-12ヶ月
- 1歳
- 2歳
- 3歳
- 4歳以上

### 3. 記事を書く

YAML設定の後に、Markdown形式で記事を書きます：

```markdown
## 見出し2

本文をここに書きます。

### 見出し3

詳細な説明をここに。

**太字** や *斜体* も使えます。

- リスト1
- リスト2
- リスト3
```

## 🚀 自動生成される機能

記事を投稿するだけで、以下が**自動的に**生成されます：

### ✅ トップページ
- 最新3件の記事が表示される
- `index.html`

### ✅ 全記事一覧
- すべての記事が日付順に表示される
- `diary.html`

### ✅ カテゴリ別ページ
- 記事のカテゴリごとに自動分類
- `category.html`

### ✅ 月齢別ページ
- 赤ちゃんの月齢ごとに自動分類
- `monthly.html`

## 📂 ファイル構成

```
your-site/
├── _posts/              # 記事を保存するフォルダ
│   ├── 2025-02-17-sleep-training.md
│   ├── 2025-02-16-baby-food-prep.md
│   └── 2025-02-15-iyaiya-taisaku.md
├── index.html           # トップページ
├── diary.html           # 日記一覧ページ
├── category.html        # カテゴリ別ページ（新規）
├── monthly.html         # 月齢別ページ（新規）
├── post-template.md     # 記事のテンプレート
└── _layouts/
    ├── default.html     # 共通レイアウト
    └── post.html        # 記事用レイアウト
```

## 🎯 使い方の例

### 例1：寝かしつけの記事を書く

1. `_posts/2025-02-17-sleep-tips.md` を作成
2. 以下を記述：

```markdown
---
layout: post
title: "夜泣きが減った！我が家の寝かしつけ術"
date: 2025-02-17
categories: [寝かしつけ]
age: "0-3ヶ月"
tags: [睡眠, 夜泣き, 赤ちゃん]
---

## はじめに

夜泣きで悩んでいたのですが...

（本文を書く）
```

3. 保存すると自動的に：
   - トップページに表示
   - 「寝かしつけ」カテゴリに追加
   - 「0-3ヶ月」月齢ページに追加

### 例2：離乳食レシピを書く

```markdown
---
layout: post
title: "簡単！作り置き離乳食レシピ"
date: 2025-02-16
categories: [離乳食, 時短]
age: "7-9ヶ月"
tags: [離乳食, レシピ, 作り置き]
---

## 材料

...
```

## 📌 Tips

### 複数カテゴリを設定
```yaml
categories: [離乳食, 時短, レシピ]
```

### 記事の抜粋を制御
最初の段落が自動的に抜粋として表示されます。

### 画像を追加
```markdown
![画像の説明](画像のパス)
```

## 🔧 トラブルシューティング

### 404エラーが出る場合
1. ファイル名の日付形式を確認（YYYY-MM-DD）
2. YAML Front Matterの記述を確認
3. Jekyllをビルドし直す

### カテゴリに表示されない場合
- `categories: [カテゴリ名]` を正しく記述しているか確認
- カテゴリ名の表記を統一（「寝かしつけ」vs「ねかしつけ」）

## 📮 今後の投稿ルーティン

毎日の投稿は以下の手順で：

1. `_posts` フォルダに新規ファイル作成
2. 日付とタイトルをファイル名に
3. YAML設定（カテゴリ・月齢）を記述
4. 本文を書く
5. 保存→自動的に分類される！

## 🎉 完成！

これで毎日記事を投稿するだけで、カテゴリ別・月齢別に自動分類されるブログが完成です！
